# Mười bộ slide: nghệ thuật Trung cổ

Mỗi file HTML trong examples là một project độc lập, gồm 20 trang và animation. Mỗi trang có một minh họa AI riêng, được nhúng trực tiếp trong HTML để luôn hiển thị kể cả khi offline. PROJECT.md chứa dàn ý slide và nguồn tham khảo. Mở [bo-slide-nghe-thuat-trung-co.html](../../../examples/bo-slide-nghe-thuat-trung-co.html) để vào từng deck.

PDF tĩnh được xuất vào output/pdf/medieval-series/. Animation chỉ chạy trong HTML.
