# Mười bộ slide: nghệ thuật Trung cổ

Mỗi file HTML trong examples là một project độc lập, gồm 20 trang và animation. Mỗi trang dùng một tác phẩm khác nhau; tên tác phẩm, tác giả, giấy phép và liên kết nguồn được ghi ở chân trang. Ảnh tải theo nhu cầu từ Wikimedia Commons nên cần kết nối Internet. PROJECT.md chứa dàn ý slide và nguồn tham khảo. Mở [bo-slide-nghe-thuat-trung-co.html](../../../examples/bo-slide-nghe-thuat-trung-co.html) để vào từng deck.

PDF tĩnh được xuất vào output/pdf/medieval-series/. Animation chỉ chạy trong HTML.
